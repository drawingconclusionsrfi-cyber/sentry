QUICK START

  1. Put sentry.html in your GitHub Pages repo, open the page on the old phone.
  2. Tap FLIP CAMERA region / allow camera + mic when asked.
  3. Set sensitivity in SETTINGS, then hit the big ARM button.
  4. Captures land in EVENTS — play, download, or auto-purge by limit.

WHAT IT DOES

  • Motion — compares frames, fires when enough pixels change.
  • Sound — watches the mic level, fires past your threshold.
  • Night vision — digital brightness boost + green/mono look.
  • Capture — snapshot, video clip, or both, stored on-device.

HONEST LIMITS

  • Night vision is software gain, not infrared — needs some ambient light.
  • Clips record the raw camera (the green tint is a preview/snapshot effect) to stay smooth on old phones.
  • Everything is stored locally (IndexedDB). Clearing browser data wipes it — use EXPORT for keepers.
  • A browser can't use the camera while the phone is locked — no web app can. Keep it plugged in, leave "keep screen awake" on, and use BLACKOUT to dim the screen near-black while it keeps recording.
  • Multi-cam: run SENTRY as HOST on each camera phone, open the VIEWER on one device, and tap ＋ ADD CAMERA for each one.

BEST SETUP

  • Plug it in (this runs the camera + screen continuously).
  • Add to Home Screen for a fullscreen, app-like launch.
  • Prop it steady — a shaky mount causes false motion hits.
